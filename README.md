# Meridian Bank - Banking Management System

A modern and responsive banking management system designed to simplify the creation and management of bank accounts through a clean and intuitive dashboard.

## Features

- Create new bank accounts
- Manage savings and checking accounts
- View total assets
- View account balances
- Display account details and account type
- Clean and responsive dashboard
- Modern banking-inspired UI

## Tech Stack

- TypeScript
- React
- Tailwind CSS
- Supabase
- Vite

## Dashboard

The dashboard provides an overview of:

- Total assets
- Number of savings accounts
- Number of checking accounts
- Individual account balances
- Account type and basic account information
